# Historical source

`v0.1/` preserves the previous `AfSsmsSqlExpander` project and its solution.
It is excluded from the active solution and CI. Develop and package only
`src/SsmsSqlExpander/` through the root `SSMS_SQL_Expander.sln`.

The archived extension uses the same VSIX identity as the current extension.
Do not install both packages together. The archive is retained for reference;
its build and host compatibility are not validated by current checks.
